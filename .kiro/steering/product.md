# プロダクト概要

`example-ai-dlc` は、ビジネスのプロジェクト管理・監視・可視化を行う
**エージェントシステム** である。AI-DLC (AI-Driven Development Lifecycle)
の実践例として、Kiro CLI による spec 駆動開発でハーネスから構築する。

## 解決する課題

- プロジェクトの進捗・リスク・依存関係が分散し、状況把握に時間がかかる
- 監視シグナル (メトリクス・アラート・イベント) とプロジェクト文脈が分断されている
- 経営層・PM・開発者で必要な可視化の粒度が異なる

## 提供価値

| 領域 | 内容 |
| --- | --- |
| プロジェクト管理 | タスク・マイルストーン・依存関係の登録と追跡 |
| 監視 | メトリクス/イベントの収集と異常検知、プロジェクトへの紐付け |
| 可視化 | ダッシュボード・タイムライン・依存グラフでの状況提示 |
| エージェント | 上記を横断し、要約・予測・推奨アクションを生成 |

## スコープ段階

本リポジトリは現在 **ハーネス段階**: front / back / infra の骨格と
Kiro CLI 設定のみが存在する。ビジネスロジックは `.kiro/specs/` の spec を
起点に後続で実装する。プレースホルダ実装を本番ロジックと取り違えないこと。
